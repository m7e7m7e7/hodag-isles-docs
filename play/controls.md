# Controls

## Keyboard and mouse

| Key | What it does |
|---|---|
| **W A S D** | Move |
| **Shift** | Run |
| **Space** | Jump (hold to jump higher) |
| **E** | Pick up, set down, talk, read |
| **Mouse** | Look around; the wheel zooms |
| **Hold left button, release** | Aim, then throw |
| **Right click while aiming** | Cancel the throw |
| **Left click** (empty hands) | Swing; **1 to 5** pick the swing |
| **R** | Climb (on the Hodag: by its claws, feet or tail) |
| **G** | Dance |
| **J** | Camp Journal (the story so far) |
| **Enter** | Chat |
| **Esc** | Free the cursor; press again to open the guide |

## Gamepad

Left stick runs (press it in to sprint), **A** jumps, **X** interacts, hold **RT** to throw, right stick or **LB / RB** turns the camera.

## Phone and tablet

On touch screens the game shows on-screen sticks and buttons.
